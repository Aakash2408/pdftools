Merge PDF

Combine multiple PDF files into one — in the order you add them. Everything runs in your browser; nothing is uploaded.

    🔒 100% private: files are processed locally with pdf-lib and never leave your device.

    How to merge PDF files

    Add two or more PDF files using the box above. They merge in the order listed — use the ✕ to remove any file, or re-add files to change the order. Click Merge & download to get a single combined PDF.

    Is it private?

    Yes. The merge happens entirely in your browser using the open-source pdf-lib library. Your files are never uploaded to a server.

    Is there a file limit?

    There's no hard limit, but very large files are constrained by your device's memory since all processing is local.
