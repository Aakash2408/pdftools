Why these tools are private

Most online PDF tools upload your file to a server to process it. These tools do the work in your browser using WebAssembly and JavaScript (PDF.js, pdf-lib, QPDF-WASM), so your document never leaves your device. Nothing is stored, logged, or transmitted.

What you can do

  • Edit text in place — the editor extracts each text run's font family, size, weight and style, and rebuilds the PDF on download.
  • Add new text anywhere on a page.
  • Password-protect a PDF with AES-256 so only people with the password can open it.
  • Search, page thumbnails, undo/redo, zoom in the editor.

No sign-up, no cost

Both tools are free to use and do not require an account. The site is supported by ads.
