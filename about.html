About PDFTools

PDFTools is a small collection of free, privacy-first PDF utilities that run entirely in your web browser.

The idea

Working with a PDF often means handing your document to a website that uploads it, processes it on a server, and asks you to trust what happens to it afterwards. For sensitive documents — statements, contracts, IDs — that is uncomfortable. PDFTools takes a different approach: the processing happens on your own device, so the file never leaves your browser.

How it works

The tools are built on well-established open-source libraries — PDF.js for rendering, pdf-lib for rebuilding edited documents, and QPDF compiled to WebAssembly for encryption. All of it executes client-side.

The tools

  • PDF Editor — edit existing text in place, keep the fonts, add new text, and download.
  • PDF Password Protector — add AES-256 password protection to a PDF.

How the site is funded

The tools are free. The site is supported by advertising, described in our privacy policy.
